# Portfolio de William Coutard

Site vitrine d'un monteur vidéo : commercials, fashion & luxury, music videos.

## Modifier le contenu

Tout le contenu est dans **`projets.js`** : une ligne par projet, avec le mode d'emploi en haut du fichier.

- Changer un titre ou une production : modifier la ligne du projet.
- Ajouter une vidéo : copier une ligne, changer les valeurs, et ajouter sa vignette dans `img/` sous le nom `<id>.jpg`.
- Choisir les projets de la page d'accueil : modifier la liste `accueil`.

Le reste du site (mise en page, lecteur) est dans `index.html`.
